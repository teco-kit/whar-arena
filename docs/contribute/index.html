Step 3 · Implement

Implementation guide

Code and tests only. No results, no raw data.

  1. 1

    Add the implementation

    Fork [Model repository] and add src/whar_models/<model_id>/ with a builder taking input_channels, window_length and num_classes.

  2. 2

    Register it

    Add it to WHARModelID and ModelSpec in registry.py.

  3. 3

    Test it

    Add a forward-pass test for varying channel, window and class counts.

    uv sync --extra dev uv run pytest
  4. 4

    Open the pull request

    Link the proposal with Closes #<issue>.

    [Pull request link]
  1. 1

    Add a parser and config

    Fork [Dataset repository] and add config/cfg_<dataset_id>.py with a parser and WHARConfig.

  2. 2

    Register it

    Add the ID to WHARDatasetID in getter.py.

  3. 3

    Test it

    Add parser tests with small synthetic fixtures. Never commit raw data.

    uv sync --extra dev uv run pytest
  4. 4

    Open the pull request

    Link the proposal with Closes #<issue>.
